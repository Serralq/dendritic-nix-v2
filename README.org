* System Design
** Dev checklist
- Search via nix-search, nix search, or nix options
- Install via nix-install <pkg-name>
- Test via nix-unlock
  with write-able config file
  - Import into NixOS
  - Delete and Copy to write-able ver to test new changes
- Do dry run using rebuild --no-save
- Clean when homemanager gives activation error
  Either manual OR create backup then find \*.backup
** Install checklist
- Heuristics, [ break rules ] chance to refactor
  - Keep all in home folder
  - Keep as regular user
  - Keep it simple
- Install checklist
  home.nix => config.nix
  - host w/ port
    Services => Docker => Install => Flatpak
  - w/o port
    Services => Install => Docker => Flatpak
